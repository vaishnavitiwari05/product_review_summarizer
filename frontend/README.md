# Frontend (React + Vite)

```bash
npm install
cp .env.example .env      # VITE_API_URL=http://localhost:8000
npm run dev               # http://localhost:5173
npm test                  # component + flow tests (vitest, jsdom)
npm run build             # production bundle in dist/
```

Backend must be running (see ../README.md). Phase 11 covers the live connection.
